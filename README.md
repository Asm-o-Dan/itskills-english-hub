# 🚀 ITSkills Academy — IT English Hub

Интерактивный веб-хаб для изучения английской IT-терминологии и визуального программирования в MIT App Inventor.

## 🌟 Возможности
- 📱 **Курс**: MIT App Inventor (12 практических уроков от «Говорящего питомца» до «Demo Day»).
- 🃏 **3D Flip-карточки**: Карточка с оригинальным IT-словом, транскрипцией, переводом, понятным определением и блоком в App Inventor.
- 🔊 **Web Speech API**: Нативное произношение на чистом американском английском по клику на динамик.
- 🎯 **Интерактивные фильтры**: Переключение между уроками 1–12 в один клик.
